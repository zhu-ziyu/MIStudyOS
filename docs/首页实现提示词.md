# 宓语 StudyOS：首页 UI 与动效实现提示词

你是桌面软件工程师、前端交互工程师、UI 还原工程师和技术美术。当前项目是 Windows 桌面软件，入口是 `app.py`，通过 Python + 原生 Windows 窗口 + WebView2 渲染内部 UI，交付 `MiStudyOS.exe`，不要将项目改成网站或要求用户在浏览器中使用。请继续完善「宓语 StudyOS」首页，目标是尽可能高度还原用户提供的 16:9 黑白线稿参考图。只做首页壳层、美术、动画和模块导航，暂时不新增课程、邮件、考试等业务逻辑。

角色「宓」必须是核心，保持参考图中人物的姿态、尺度、位置、线稿与留白。左右各四个功能翼片：左侧为课程中心、日程日历、作业工作台、记忆卡片；右侧为写作工坊、考试与错题本、校园信箱、原创表达优化。下方中央为今日学习总览和成绩追踪器。所有标题、搜索、日期、欢迎语、按钮文案与头像布局紧贴参考图。

保留原素材库 `assets/lineart`。独立 4K 素材包在 `resource-packs/MiStudyOS_Home_4K_AssetPack`。复用现有 PNG、SVG、manifest、参考母图和分镜，不把现有素材库移动到写作工坊。边框、文字、图标、箭头、花枝、对话框与角色分组独立。文本使用真实 DOM；不得把整个页面做成一张截图加透明点击区。参考母图可以在 SVG viewBox/mask 内采样为独立美术层，但必须明确其栅格来源，不能称为真正重新绘制的矢量资源。

出场动画约 6.8 秒：纸面与远景 → 角色轮廓描线与分组显现 → 标题和顶部信息 → 左右翼片从内向外交替生长 → 中央两张卡片 → 前景书卷 → 对话边框与文字 → 第一次自然眨眼 → 安静呼吸。不要整屏一起跳入，不要夸张缩放。逐线动画可以用真正的 SVG 引导线与分组遮罩结合；未经逐路径分层，不得声称完整逐笔复原。

闲置动效保持克制：呼吸 Y 约 1px、scale 约 1.001、随机眨眼、鼠标跟随最多 1–2px，蝴蝶每十多秒仅动一次。翼片 hover 上移 2px，图标轻放大 1.02，箭头平移 2px。中央卡片、对话框和顶部按钮遵循同样安静的动效语言。补充流苏或头发叠层时，先确认资源确实独立且不重复叠出黑线。

任何时刻跳过动画，都要呈现完整 UI 并收敛到稳定姿态。尊重 prefers-reduced-motion，保留约一秒分组淡入，关闭描线、展开、呼吸与视差。控制必须支持键盘、可读名称、焦点和 Esc；小屏要重新排版成可读卡片，不将整幅桌面海报缩成无法点击的小图。

「墨笺·宓语 / Writing Studio」收纳原项目所有现有功能，但先读取实际源代码与运行方式。保持原业务逻辑、快捷键、状态和持久化格式不变，通过入口适配器纳入新壳层，不做重写。当前工作区没有旧写作源码；必须在取得源码路径后才能声称完成迁移。Web 项目可使用 `config/studyos.json` 的 URL 适配，原生项目需要保留原启动入口。素材库不并入写作子模块。

校园信箱 UI 可以标注未来接 Outlook / Microsoft Graph；当前不请求权限，不编造真实通知。原创表达模块采用个人文风、句式、原创观点与引用检查文案，不对 AI 检测结果做保证。

完成后启动本机预览，核对 1672×941 与 1280×720 桌面、390px 小屏、正常/跳过/减少动态效果模式、10 个入口、搜索和设置。逐张检查真实截图，修正字体、遮挡、重复文字、裁切和图层接缝。交付源码、独立素材包、动画说明、验证报告与可复用提示词；不要把高度还原目标当成已经量测达到的“99%”承诺。
