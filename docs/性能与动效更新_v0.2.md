# v0.2 桌面性能与动效更新

2026-10-08 更新，入口仍为根目录的「启动宓语StudyOS.cmd」或 app.py。桌面 EXE 与 ZIP 同步更新。

## 体验

- 日常进入播放 2.4 秒出场；「重绘此刻」播放 4.8 秒完整绘制。
- 细线先行，墨迹从发冠向衣袖连贯收笔；双翼沿曲线由中央向外生长，以独立铰点轻轻回弹落定。
- 宓会随鼠标偏头、低频眨眼与偶尔双眨，呼吸和发丝存在轻微时差；点击角色或对话框会回应。
- 弹窗打开、窗口隐藏或关闭动态效果时暂停持续绘制。

## 渲染

首页出场与闲置状态共用一次连续原画 GPU 绘制。预编译 1,284 条原画线迹为数值时序场，避免每帧遍历 SVG 线迹与合成多张整屏画布。共享花枝与发丝使用连续反向采样，避免切片移动造成白块和接缝。

闭眼素材在独立工作线程解码、配准，主线程只接收 176×104 的眼部图集。首页不再等待闭眼大图，不再预加载 4K 纸纹；保留原画中的纸面。固定本机来源允许后续启动复用美术缓存。品牌文字直接随壳层显示。

## 本机验证记录

| 项目 | 优化前源码采样 | 最终 EXE 采样 |
| --- | ---: | ---: |
| 原生初始化到首页 API 就绪 | 5614.6 ms | 2874.0 ms |
| 日常出场时长 | 6800 ms | 2400 ms |
| 完整重绘的绘制间隔 P95 | 20.0 ms | 18.5 ms |
| 完整播放中超过 50 ms 的间隔 | 3 | 0 |

初始化计时从应用 main 开始，含桌面运行时初始化；不含 EXE 引导程序载入。两次运行的缓存状态不同，表格记录本次采样，不能视为任意电脑上的保证。播放数据统计实际绘制调用的间隔，未把所有 requestAnimationFrame 回调当作已绘制帧。

原生检查覆盖 13 个出场阶段、半闭眼与闭眼、重播中断、减少动态效果、鼠标注视和弹窗暂停。UI 回归检查覆盖 10 个模块入口、搜索、设置保存和窗口适配。

报告位于 artifacts/performance-baseline.json、artifacts/performance-release.json 与 artifacts/desktop-verification.json。
