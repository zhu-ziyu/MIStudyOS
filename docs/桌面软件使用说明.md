# 宓语 StudyOS · 桌面版

打开 `MiStudyOS.exe` 即可进入书房。`_internal` 目录包含软件运行文件，需与 EXE 一起保留。软件不需要浏览器、Node.js 或额外的 Python 安装；Windows 使用已安装的 Microsoft WebView2 Runtime。

首页包含左右 8 个模块入口与中央 2 个总览入口。当前版本先完成 UI 与动效，课程、邮件、成绩等业务数据暂未接入。

进入书房的出场动画约 6.2 秒：角色沿发丝、眉眼和衣袖轮廓逐笔画出线稿，随后填上墨色与明暗；停顿后四对翅膀逐排展开，中央完整外框与两张卡片依次落定，最后出现欢迎区。可点击首页、按 Esc 或点击「跳过动画」直接进入。「重绘此刻」重播同一套节奏，「静止画卷」开关微动效。宓会轻轻呼吸、随鼠标偏头，点击角色或对话框会回应；打开模块后，首页动效暂停。搜索可以查找模块，Ctrl+K 聚焦搜索。

宓是一位冷淡、克制的学姐。点击角色或她的对话框，她会回应一句，例如「你是来学习的，不是来戳我的。」「戳我，不算学习进度。」连续戳她，会给出「还在戳？作业写完了？」等提醒；快速点击不会堆积讲话。

讲话带小幅口型与轻微点头，在句读处停顿。此版本为文字与动画，不播放语音。23 句预设台词全部保存在本机，不需要联网；首页每隔约 1–2 分钟随机提醒一次。搜索、输入、打开模块、切换到其他窗口或隐藏软件时暂停，回到首页重新计时。

右上角设置可修改称呼、出场动画、动效偏好和「让学姐偶尔提醒我」，保存在软件目录的 `.studyos-data`。关闭主动提醒后仍可手动点击回应。「静止画卷」及系统减少动态效果模式会关闭讲话动作，直接显示完整台词。窗口使用原生最小化、最大化和关闭按钮。

「墨笺·宓语」为原写作功能的接入入口。配置在 `config/studyos.json`：原 Python/EXE 工具填写 `entryPath`，Python 工具同时填写 `pythonExecutable`；保留原源码与原功能逻辑。

完整 4K 美术库单独交付为 `MiStudyOS_Home_4K_AssetPack.zip`，不需要解压到写作模块中。
