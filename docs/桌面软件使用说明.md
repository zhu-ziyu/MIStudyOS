# 宓语 StudyOS · 桌面版

打开 `MiStudyOS.exe` 即可进入书房。`_internal` 目录包含软件运行文件，需与 EXE 一起保留。软件不需要浏览器、Node.js 或额外的 Python 安装；Windows 使用已安装的 Microsoft WebView2 Runtime。

首页包含左右 8 个模块入口与中央 2 个总览入口。当前版本先完成 UI 与动效，课程、邮件、成绩等业务数据暂未接入。

首次出场动画约 6.8 秒，可点击首页、按 Esc 或点击「跳过动画」直接进入。下方「重绘此刻」重播动画，「静止画卷」开关微动效。搜索可以查找模块，Ctrl+K 聚焦搜索。

右上角设置可修改称呼、出场动画与动效偏好，保存在软件目录的 `.studyos-data`。窗口使用原生最小化、最大化和关闭按钮。

「墨笺·宓语」为原写作功能的接入入口。配置在 `config/studyos.json`：原 Python/EXE 工具填写 `entryPath`，Python 工具同时填写 `pythonExecutable`；保留原源码与原功能逻辑。

完整 4K 美术库单独交付为 `MiStudyOS_Home_4K_AssetPack.zip`，不需要解压到写作模块中。
