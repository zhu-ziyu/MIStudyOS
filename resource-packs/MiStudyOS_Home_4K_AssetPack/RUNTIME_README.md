# 首页运行时资源补充

原始四包保持原文件和目录。

- 14_runtime_svg：按照实际参考坐标导出的十个边框、十个独立图标、对话框、头像和前景；使用 SVG viewBox/mask 采样，不是重新绘制的矢量线稿。保留旁边的 00_reference 文件夹，确保相对图像链接可用。
- 15_reusable_decor：从原 assets/lineart 原样复制的独立花朵、花枝、流苏、蝴蝶、山水等 SVG，可按需补充局部动画。
- 12_manifest/runtime_manifest.json：准确位置、分类、建议动画、z-index 与安全范围。

背景/远景 z0–5；角色 z9；翼片边框 z15；图标/文字 z16；中央卡 z20；书卷前景 z22；对话与真实 UI z25–35。所有装饰 pointer-events:none，业务交互由 DOM 按钮承担。

导出尺寸 4096 表示设计尺度或栅格放大，不能把源图放大称为新增真实 4K 细节。原 PNG 带透明通道，但部分装饰区域含参考图纸纹；要求完全清洁、无遮挡的分层 master 时，需要原分层工程或重绘。
